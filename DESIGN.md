# Rooftop station

Abrar’s New York rooftop is an illustrated setting for an engineer whose old gaming PC became a host. The original pixel art borrows the sense of place and play from Krillion. A first-time visitor can go straight to a talk, a code repository, a career entry, or the server tour.

## Type and color
Self-host Archivo Black for the name and headings. Use system sans for prose and IBM Plex Mono for navigation, dates, and links. Warm cream (#fff1d9) on deep blue-black (#141923) is the reading surface. Sunset orange (#ff9861) marks the main action. A pale mint field gives the server tour its own place in the page.

## Layout and interaction
Pair the name and introduction with the rooftop scene. Let the hero stack on phones. Follow it with ruled project rows, a service glossary, career history and contact. Use native links, visible keyboard focus, and normal document scrolling. Keep animation optional and keep all information accessible without scripts.

## Illustration
The rooftop illustration is an original image generated with OpenAI ImageGen. The scene includes a Brooklyn rooftop workshop, an amber CRT and server, a rooftop antenna, a pigeon, and a layered skyline at sunset. The buildings and workshop are imagined.
